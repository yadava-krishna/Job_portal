## PRODUCT VISION / COMPLETE CANDIDATE JOURNEY

JobPilot is a **career execution and feedback system**, NOT a job-application bot. The recurring loop is **Discover → Diagnose → Build → Present → Apply → Interview → Reflect → Improve**. All modules must preserve this connected graph and move the candidate toward an honest next action. Prioritize better decisions and hiring outcomes over application count.

Personas: student/graduate, early-career candidate, experienced professional, internationally mobile candidate and human mentor. UX must use progressive disclosure: first session shows key matches/gaps/editable resume/one clear next step; add tracker/analytics after applications; interview reflection when relevant; focused learning after repeated gaps; verified country/visa views on international intent; useful mentor insights when evidence exists. Do not overwhelm first-time candidates with huge dashboards or endless settings.

### C. Match vs eligibility vs gap diagnosis [P0]

- Separate **job suitability match** from **hard eligibility/work permit**. Display explainable breakdown and source facts, not a mysterious single percentage. Unknown salary/authorization must remain `unknown`, not silently treated as pass or fail.
- Start with the document's configurable, versioned scoring dimensions adding to 100%: required skills **30%**; experience **20%**; responsibilities **15%**; education/certifications **10%**; location/work mode **10%**; industry/domain **5%**; salary **5%**; work authorization/sponsorship **5%**. Store `score_version` and component breakdown for each JobMatch. Calibrate over time with measured outcomes, not unvalidated predictive certainty.
- Normalized skills/aliases, candidate proficiency, years, requirement importance, hard/soft requirement type, responsibility similarity and supporting skill evidence. Generate specific gaps with severity, explanation, job/goal linkage and next action.
- A transparent skill progression model: `Aware → Learning → Practising → Project Evidence → Professional Experience → Interview Ready`. These states are **not interchangeable**: courses and projects must never be represented as employment history. Track evidence type, links, verification, timestamps and provenance. Resume rewriting must obey these states.
